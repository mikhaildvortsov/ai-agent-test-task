Тестовое задание на позицию AI-оператор / AI-агент.

## Что в репозитории

| Файл | Описание |
| --- | --- |
| `CityCar_тестовое_задание.pdf` | Ответы на шесть вопросов: архитектура, граница автоматики и человека, риски, код, AI-проект, обучение и улучшение |

## Запуск кода

```bash
pip install requests
# подставьте SUBDOMAIN и ACCESS_TOKEN в amo_deals_check.py
python amo_deals_check.py
```

Код не запускался против реальной amoCRM. Логика поиска проблемных сделок (`find_problem_deals`) проверена на тестовых данных.
